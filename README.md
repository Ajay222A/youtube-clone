🎥 YouTube Clone

A simple and responsive YouTube Clone website created using HTML and CSS.

This project is designed to recreate the basic look and feel of the YouTube homepage while practicing frontend web development concepts.

📌 About the Project

The YouTube Clone is a frontend website created to practice and demonstrate my knowledge of HTML5 and CSS3.

The website includes a YouTube-inspired navigation bar, sidebar, search bar, video thumbnails, video titles, channel information, and other user interface elements.

The main goal of this project is to improve my understanding of web page structure, CSS styling, layouts, positioning, Flexbox, and responsive design.
